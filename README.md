<p align="center"><strong>dsh-cnc — CNC 转速进给与 DFM</strong></p>

按材料/刀具算转速与进给，检查圆角、深孔、薄壁。

## 安装

    dsh plugin --profile web add github:moldkey/dsh-cnc

## 工具

- `cnc_speed_feed`：S/F 计算
- `cnc_dfm`：可加工性检查

更多工具：https://deepseekbase.com/zh/tools/
